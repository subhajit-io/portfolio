BRAND GOVERNANCE • MULTI-WORKER RAG ENGINE

ZUARD

DEPLOYED ON VERCEL
Real-Time Brand Governance, Sub-5ms Pre-Screening & Branched Multimodal RAG

Co-engineered Zuard as a high-performance brand governance and compliance pre-screening engine for enterprise marketing and publishing workflows. Implements a high-velocity two-stage pipeline: 4 concurrent deterministic static workers execute in parallel via asyncio.gather (< 5ms, $0 LLM cost) verifying lexical tone (Flesch-Kincaid & Gunning Fog), terminology dictionaries, boundary-aware superlative claims, facts verification against SQLite, OpenCV K-Means visual harmony, and WCAG 2.1 accessibility contrast math. Flagged snippets are synthesized by a Delta-Only Synthesizer with Branched RAG citing exact guideline page and section references with zero hallucinations.

  • Sub-5ms Deterministic Pre-Check: 4 parallel workers checking 90%+ mechanical compliance rules with zero LLM API cost.
  • Zero-Hallucination Branched RAG: PyMuPDF document hierarchy chunker with hybrid semantic TF-IDF retrieval citing exact page IDs.
  • Multi-Project Isolation: Isolated SQLite facts databases, dynamic guideline ingestion, and two-sided Creator vs Reviewer portals.
